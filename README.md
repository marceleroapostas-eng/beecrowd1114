# Beecrowd 1114 - Senha Fixa

## Descrição
Programa desenvolvido em Java para solicitar uma senha até que o usuário informe o valor correto, que é 2002.

## Linguagem
Java

## Entrada
O programa recebe valores inteiros correspondentes às senhas digitadas pelo usuário.

## Saída
Imprime "Senha Invalida" para cada senha incorreta e "Acesso Permitido" quando a senha correta for informada.
